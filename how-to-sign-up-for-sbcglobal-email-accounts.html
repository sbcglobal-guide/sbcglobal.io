Check the device application

Review incoming and outgoing server settings

For advanced client configuration, incoming mail and outgoing mail are separate components. IMAP keeps messages synchronized across devices, while SMTP handles sending. A typo in either server name, a wrong port, or a mismatched security setting can disrupt one direction of mail even when the other works. The provider currently documents imap.mail.att.net with secure IMAP on port 993 and smtp.mail.att.net with secure SMTP on port 465. Check the latest provider help documentation before changing these values.
